# Fold6 최소 앱 검증 기록

이 문서는 `0.1.0`의 당시 동작 기록이다. `0.2.0`부터 잠금·충전·가로 조건이 모두 필요하며, 현재 동작과 결과는 [조건 검증 기록](fold6-conditions-validation.md)을 기준으로 한다. 아래 빌드 보고서 경로는 새 빌드 시 최신 결과로 바뀐다.

검증일: 2026-10-23. 충전 자동 진입, 잠금 위 표시, 펼침·책·탁상·커버 전환을 실제 Fold6에서 확인했다. 물리적인 USB 재연결과 접힘 조작은 사용자가 수행했고, 앱 기록·UI 텍스트·화면 캡처를 함께 대조했다. 배터리 상태나 접힘 이벤트를 주입하지 않았다.

## 빌드와 설치

| 항목 | 결과 |
|---|---|
| 기기 | Galaxy Z Fold6, `SM-F956N` |
| OS | Android 16, SDK 36, One UI 속성 `80500` |
| 앱 | `dev.kwonsu.standby`, `0.1.0` / versionCode 1, debug |
| 빌드 | `assembleDebug` 성공 |
| 단위 테스트 | `testDebugUnitTest`: 12개 통과, 실패·오류·건너뜀 0 |
| 정적 검사 | `lintDebug`: 오류 0, 경고 11 |
| 설치 | 실제 기기 `adb install -r` 성공, launcher Activity 실행 성공 |

단위 테스트는 연결 기준점·중복 이벤트·재연결, 네 가지 화면 배치 선택, 실제 힌지 두께·편심 위치·오래된 경계·작은 창의 분할 계산을 다룬다. Android OS의 백그라운드 실행 정책은 단위 테스트 범위가 아니다.

Lint 경고는 의존성 업데이트 7건, AGP 업데이트 1건, target API 업데이트 1건, 명시적 데이터 이전 규칙 권고 1건, `toUri` 사용 권고 1건이다. 이번 앱은 Android 16을 target으로 빌드했다. 백업은 `allowBackup=false`이나 제조사별 기기 이전 동작은 검증하지 않았다.

- 단위 테스트 XML (`app/build/test-results/testDebugUnitTest/TEST-dev.kwonsu.standby.PoliciesTest.xml`, 로컬 전용)
- Lint 보고서 (`app/build/reports/lint-results-debug.html`, 로컬 전용)

충전 자동 진입은 서로 다른 두 `attempt`에서 실제 Activity 활성화까지 확인했다. `startActivity()`의 반환만을 성공 근거로 사용하지 않았다. 잠금 위 표시는 `isKeyguardLocked=true`와 화면 표시를 확인한 결과이며, 잠금 해제 우회 기능은 구현하지 않았다.

탁상 캡처의 화면은 `2160×1856px`이다. 수평 힌지는 `y=928`, 시계 텍스트는 `y=228..612`, 조작부 제목은 `y=988..1039`에 있어 힌지 위아래로 나뉜다. 전환 중 WindowManager의 새 힌지 정보와 창 크기가 순차적으로 도착하는 일시적 중간 기록은 있었으며, 최종 배치와 화면을 기준으로 판정했다.

첫 화면 확인에서 배터리 숫자·안내 문구가 검은 배경에 묻히는 문제를 발견했다. Compose `Surface`에 전경색을 지정해 수정하고 빌드·단위 테스트·Lint를 다시 통과한 APK로 이후 실기기 검증을 수행했다.

## 아직 확인하지 않은 범위

시스템 화면보호기는 후속 실기기 검증에서 목록 선택·미리보기·유휴 자동 진입·탭 종료·USB 해제 종료를 통과했다. 세부 근거와 설정 복원은 [시스템 화면보호기 검증 기록](fold6-dream-validation.md)에 있다.

| 범위 | 상태·다음 확인 방법 |
|---|---|
| 권한 거절·회수 후 알림 진입 | NotRun. 분기 구현은 있으나 실제 권한 거절 상태의 연결 시험은 하지 않음 |
| 무선 충전·배터리 보호·완충 | NotRun. 전원 종류와 연결 여부를 구분하나 실제 조건 시험은 하지 않음 |
| 재부팅·앱 강제 종료·프로세스 종료 | NotRun. 자동 감시 복원은 구현하지 않았으며 사용자가 앱에서 다시 켜는 설계 |
| 장시간 사용 | NotRun. 발열·배터리 소모·번인·One UI 절전 정책의 장시간 영향 측정 필요 |
| 다른 기기·OS·글자 크기·분할 화면 | NotRun. 현재 결과는 위 Fold6 설정에 한정 |

이번 기기에서는 펼침에서 커버로 시계가 이어졌지만, ‘커버 화면에서 앱 계속 사용’ 설정 자체는 별도로 변경하거나 검사하지 않았다. 다른 설정에서의 동일 동작을 보장하지 않는다.

## 재검증 순서

1. 앱의 자동 실행 권한·알림을 허용하고 충전 감시를 켠다.
2. 기기를 잠그고 USB를 뺐다가 3초 이상 뒤 연결한다. 잠금 위 시계 표시를 확인한다.
3. 완전히 펼침 → 세로 90도 반접힘 → 가로 90도 탁상 자세 → 커버 복귀를 각각 5초 이상 유지한다.
4. 야간 모드를 켠 뒤 USB를 뺀다. 시계가 닫히는지 확인한다.
5. 다시 연결해 자동 진입과 야간 설정 유지를 확인한다.
6. `python3 scripts/collect-device-evidence.py --serial <기기-ID>`로 앱 기록을 수집한다.

현재 기기는 충전 감시와 야간 모드가 켜진 상태다. 테스트를 중단하려면 알림의 **감시 종료** 또는 앱의 **충전 감시 끄기**를 사용한다.
