# 사용 가이드와 변경 이력

Galaxy Z Fold6용 가로 스탠바이 시계. **화면 잠금 + 충전 연결 + 가로 자세**가 모두 성립할 때만 자동으로 나타나고, 하나라도 해제되면 사라진다. 현재 소스 버전은 `0.13.0`이다. 설치·기기 검증 상태는 버전별 검증 기록에서 확인한다.

## 사용 방법

1. **자동 실행 권한 설정**에서 이 앱의 **다른 앱 위에 표시**를 허용한다.
2. **자동 스탠바이 켜기**를 누르고 알림을 허용한다.
3. 충전기를 연결하고 화면을 잠근 뒤 기기를 가로로 세워 둔다. 조건이 약 0.8초 유지되면 시계가 나타난다.
4. 잠금을 풀거나, 세로로 돌리거나, 충전기를 빼면 시계가 자동으로 닫힌다.

세 조건의 순서는 상관없다. 이미 충전 중인 기기를 가로로 돌리거나 다시 잠글 때도 조건을 확인하므로 충전기를 다시 꽂을 필요가 없다. 충전만 연결한 상태나 잠금이 해제된 상태에는 시계를 표시하지 않는다.

시계의 **닫기** 버튼으로 닫으면 조건이 한 번 해제되었다가 다시 성립할 때까지 자동으로 다시 열지 않는다. 알림을 누르면 앱 설정을 열며, 알림의 **감시 종료** 또는 앱의 **자동 스탠바이 끄기**로 감시를 중단한다. 앱 강제 종료·프로세스 종료·재부팅 후에는 앱에서 다시 켠다.

시계는 가로만 지원한다. 화면 크기가 달라져도 사용자가 정한 위치와 크기 비율을 유지한다. 커버 화면으로 계속 이어 보려면 One UI의 **설정 → 디스플레이 → 커버 화면에서 앱 계속 사용**에서 이 앱을 허용한다. 버전별 실기기 검증 범위는 [0.3.0 꾸미기 검증](fold6-customization-validation.md), [0.2.0 조건 검증](fold6-conditions-validation.md)에서 확인한다.

## 화면 꾸미기

앱의 **화면 꾸미기**에서 변경하고 **저장**하면 스탠바이에 적용된다. 편집 중인 내용은 임시 저장되며, 나갈 때 저장하거나 마지막 저장 상태로 되돌릴 수 있다. **전체 화면 편집**을 누르면 시스템 표시줄을 숨기고 실제 기기의 가로 화면 크기로 편집한다. **화면만 보기**로 선택 테두리와 편집 도구를 숨기고, **편집 도구**로 돌아온다.

| 항목 | 설정 |
| --- | --- |
| 폰트·색상 | 기본 글꼴과 선택 글꼴(개별 사용 권한을 확인해 로컬에 추가한 경우), 색상 팔레트와 6자리 HEX |
| 배경 | 단색, 오로라·노을·심해·샌드 프리셋, 직접 선택한 사진 |
| 사진 배치 | 채우기·맞추기·늘이기, 확대, 좌우·상하 위치, 가로·세로 비율, 어둡게 하기 |
| GIF | 여러 파일 추가, 위치·크기·투명도·맞춤 방식, 각각 0.25~3배 속도와 반복 여부 |
| 화면 요소 | 시계·날짜·배터리·야간 버튼·진단 버튼·닫기 버튼·밝기 슬라이더·출퇴근 게이지 추가 및 제거, 요소별 글자색 |
| 배치 | 전체 화면·작은 캔버스에서 끌어 이동, 네 모서리로 크기 변경, 슬라이더 세부 조정, 화면 가장자리 맞춤, 앞뒤 순서, 위치·크기 고정, 중앙 정렬 가이드 |
| 글자 크기·정렬 | 시계·날짜·배터리의 왼쪽·가운데·오른쪽 정렬, 자동 맞춤 또는 별도 글자 크기 |
| 겹친 요소 선택 | 요소 목록에서 선택, 내용의 앞뒤 순서를 유지하면서 선택 테두리·손잡이만 가장 위에 표시 |

GIF 반복을 끄면 한 번 재생한 뒤 마지막 프레임을 유지한다. 속도·반복 설정을 바꾸거나 시계를 다시 열면 처음부터 재생한다. 야간 모드에서는 글자색을 붉은색으로 바꾸고 화면을 어둡게 한다.

작은 편집 캔버스의 비율은 커버·16:9·내부 화면 중에서 선택한다. **전체 화면 편집**과 실제 시계는 현재 기기의 화면 비율을 사용하므로 작은 캔버스와 여백·사진 잘림이 달라질 수 있다. 직접 추가하는 요소는 최대 20개이며 공통 배치로 자동 추가된 요소를 포함하면 최대 40개다. 한도를 넘는 공통 변경은 저장하지 않고 안내하며, 기존 요소를 삭제하지 않는다. 힌지 위치에 따라 자동으로 재배치하지 않는다. **기본 배치**는 추가한 GIF와 요소 배치를 초기화하며, 저장해야 실제 시계에 적용된다.

시계를 오른쪽에 붙이려면 **요소 목록 → 시계 → 조정 → 오른쪽 끝**을 누른다. 시계·날짜·배터리는 현재 글자 크기를 유지하면서 자동으로 **내용에 맞춘 영역**을 사용한다. **좌우 내부 여백 (%)**에 원하는 값을 입력하고 **여백 적용**을 누른다. 여백은 선택 테두리와 내용 사이의 간격이다. `0`은 내용에 밀착하며, `5`는 컴포넌트 너비의 5%를 왼쪽과 오른쪽에 각각 확보한다. **위아래 내부 여백 (%)**은 컴포넌트 높이 기준이며, 화면 끝 배치 버튼은 외곽 영역을 화면 끝에 붙인다.

**내용에 맞춘 영역**에서는 **내용 크기**와 네 모서리로 크기를 조절한다. 내부 여백을 늘리면 글자 크기를 유지하면서 외곽 영역이 커진다. 전체가 화면보다 클 때만 화면 안에 맞춰 줄인다. 오른쪽에 붙인 요소를 왼쪽 모서리에서 키우면 오른쪽 외곽과 글자의 비율을 유지한다. 선택 테두리·손잡이 표시는 영역 바깥에 두어 여백이 0이어도 글자를 가리지 않는다. 직접 드래그하거나 위치 슬라이더를 움직이면 해당 가장자리 맞춤을 해제한다. 내용 맞춤을 끄면 기존 박스·글자 정렬·자동 크기 방식으로 조정한다. 이미 저장된 요소는 새 기능을 선택하기 전까지 기존 표시를 유지한다.

전체 화면 도구 막대는 **도구 위로 / 도구 아래로**로 옮기며, 가려진 요소는 **요소 목록**에서 선택한다. **닫기**는 편집 내용을 유지한 채 일반 편집 화면으로 돌아간다. **저장**은 기존 저장 흐름을 따르며, 불러온 프리셋이 바뀌었으면 프리셋 반영 여부를 확인한다. 공통 요소는 **공통 배치 편집 → 전체 화면 편집**에서 조정하고 **공통 저장**한다. 내용 맞춤을 사용하면 내용 크기·가장자리 기준·내부 여백도 공통 배치에 포함한다. 폰트·색상·기존 글자 스타일 값과 각 프리셋의 원래 배치는 보관하며 연결 해제 시 복원한다.

사진과 GIF는 시스템 파일 선택기로 고른 파일만 앱 내부에 복사한다. 원본 파일을 옮기거나 지워도 저장한 복사본을 사용하며, 저장·편집 취소 시 더 이상 사용하지 않는 앱 내부 복사본을 정리한다. 파일당 최대 20MB, GIF는 약 210만 화소까지 지원한다. 사진은 긴 변을 최대 2048px로 줄여 표시한다.

### 밝기·위치 고정·정렬

- **요소 → + 밝기 슬라이더**로 배치한다. 뒤쪽 화면을 흐리게 비추는 반투명 유리 표면과 얇은 테두리로 표현하며, 슬라이더 자체에 색상 그라데이션을 넣지 않는다. 조작 중 선명해지고 손을 뗀 뒤 1.4초 후 0.3초에 걸쳐 흐려진다. 완전히 사라지지는 않아 다시 조작할 위치를 찾을 수 있다.
- 밝기는 스탠바이 창에만 적용되며 시스템 밝기 설정을 바꾸지 않는다. 최소 2%부터 100%까지 조절하고, 일반·야간 밝기를 각각 기억한다. 편집 화면의 미리보기에서는 슬라이더 모양만 시험한다.
- **위치·크기 고정**을 켜면 드래그·크기 손잡이·좌표/크기 슬라이더를 잠근다. 선택·색상·기타 속성 수정과 의도적인 제거는 가능하다.
- **중앙 정렬 가이드**를 켜 두면 드래그 중 다른 요소나 화면의 가로·세로 중앙에 가까워질 때 파란 보조선과 스냅을 제공한다. 스냅 범위를 벗어나면 자유롭게 움직이고, 손을 떼면 보조선이 사라진다.

### 출퇴근 게이지

1. **화면 꾸미기 → 요소 → + 출퇴근 게이지**로 추가하고 위치와 크기를 정한다. **게이지 방향**에서 가로·세로를 선택한다. **게이지 색상**의 팔레트·6자리 HEX로 원하는 색을 고르고 **저장**한다. 기본값은 기존 청록색이며 **기본 청록색 사용**을 켜면 되돌릴 수 있다. 순환 프리셋에서 쓰려면 해당 프리셋에도 저장한다.
2. 스탠바이에 처음 표시되는 **출근**을 누르면 큰 시계 다이얼이 열린다. 실제 출근한 시각을 고르고 **HH:mm 출근**으로 확정한다. 취소하면 근무를 시작하지 않는다.
3. 선택한 시각부터 진행률을 계산한다. **08:00 이전 또는 08:00 출근 → 당일 17:00**, **08:01 출근 → 17:01**, **09:30 출근 → 18:30**이다. 늦게 입력해도 이미 지난 시간을 반영한다.
4. 가로는 왼쪽에서 오른쪽으로, 세로는 아래에서 위로 채워진다. 퇴근 예정 시각은 게이지 오른쪽 위의 작은 배지에 표시한다. 선택한 색상은 막대·프레임·퍼센트·시각 배지·출근 버튼에 함께 적용되며, 야간 모드에서는 붉은 계열로 표시한다. 출근 버튼은 짙은 바탕으로 배경과 구분하고, 너무 어두운 선택 색상은 버튼 글자만 밝게 보정한다.
5. **100%가 되면 자동 퇴근**한다. 전체 화면 폭죽이 약 4.2초 재생된 뒤 **출퇴근 게이지만** 숨겨지며 수동 퇴근 버튼은 없다. 시계·날짜·배터리·배경·GIF와 스탠바이 자동 진입은 기존 잠금·충전·가로 조건에 따라 유지한다. **100%가 된 예정 퇴근 시각부터 12시간 후** 출근 버튼이 다시 나타난다. 예를 들어 17시에 완료되면 다음 날 05시부터 다시 출근할 수 있다.

잘못 입력한 출근 시각은 **실제 스탠바이의 출퇴근 게이지를 길게 눌러** 수정한다. 현재 저장된 시각이 선택된 **출근 시각 변경** 화면에서 새 시각을 고르고 **HH:mm로 변경**을 누른다. 취소하거나 같은 시각으로 확정하면 기존 기록을 유지한다. 가로·세로 게이지 모두 지원하며, 꾸미기 화면의 미리보기에는 적용하지 않는다.

새 출근의 날짜는 다이얼 상단에 표시된 당일이다. 기존 출근 시각을 수정할 때는 자정을 넘겼어도 원래 출근 날짜를 유지한다. 미래 시각을 선택하면 그때까지 0%로 기다린다. 퇴근 예정 시각은 선택한 출근 시각에 9시간을 더한 때와 당일 17시 중 더 늦은 시각이다. 밤에 시작한 근무는 다음 날 끝날 수 있다.

근무 상태·완료 여부·12시간 대기는 앱 재시작과 프리셋 전환 후에도 이어진다. 여러 프리셋의 게이지가 같은 근무 상태를 공유한다. 게이지가 표시되지 않는 동안 완료되면 다음 표시 시점에 예정 퇴근 시각으로 자동 퇴근을 기록한다. 12시간 이내라면 폭죽을 한 번 재생하고 남은 시간 동안 게이지만 숨기며, 이미 12시간이 지났다면 과거 폭죽을 재생하지 않고 출근 버튼을 표시한다.

폭죽은 활성 화면이 포커스를 얻은 뒤 시작하고, 약 4.2초 재생을 마친 뒤 재생 완료를 저장한다. 화면 회전·프리셋 전환·다른 창으로 중단되면 12시간 이내의 다음 표시 때 다시 재생한다. 밝은 배경에서도 입자가 보이도록 어두운 외곽을 함께 그린다. 이전 버전에서 재생 완료로 저장한 기록은 유지한다. 구버전에서 수동 퇴근하여 출근·예정 퇴근 시각이 모두 지워진 기록은 정확한 마감을 복원할 수 없어 대기를 한 번 해제한다. 편집기의 65% 표시는 모양 확인용이며 실제 출근 기록을 만들지 않는다. 출퇴근 게이지도 공통 배치에서 선택할 수 있으며, 게이지 방향과 색상은 각 프리셋에서 유지한다.

### 화면 프리셋과 순환 목록

1. **프리셋** 탭에서 이름을 입력하고 **현재 화면을 프리셋으로 저장**한다. 폰트·배경·GIF·요소 배치·위치 고정을 함께 보관한다. 현재 편집 내용의 복사본이며, 상단 **저장**은 현재 기본 디자인에 적용하는 동작이다.
2. 원하는 프리셋만 **순환에 추가**한다. 목록의 **위로·아래로**로 순서를 정하고 **목록에서 빼기**로 제외한다. 목록에서 빼도 저장한 프리셋 자체는 남는다.
3. **프리셋 순환**을 켠다. 새 스탠바이 진입 또는 잠금 상태에서 화면을 껐다 켤 때마다 다음 프리셋을 표시한다. 마지막 다음에는 첫 프리셋으로 돌아간다. 회전·접힘에 따른 화면 재생성은 같은 선택을 유지한다.
4. 스탠바이에서 배경을 위나 아래로 스와이프하면 목록의 다음 프리셋으로 넘긴다. 두 방향 모두 기존 순환 순서의 다음 화면으로 이동한다. 밝기 슬라이더 위의 드래그는 밝기만 바꾼다.

순환을 끄거나 목록이 비면 현재 저장된 기본 디자인을 표시한다. 등록한 프리셋이 하나면 그 화면만 표시한다. 마지막 선택은 저장되어 다음 진입에 이어진다. 목록에 없는 프리셋은 표시하지 않는다.

프리셋은 최대 32개까지 저장하고 이름 변경·불러오기·덮어쓰기·삭제를 지원한다. 편집 중인 변경을 대체하거나 프리셋을 덮어쓰고 삭제할 때 확인 창을 표시한다. 순환에서 제외한 프리셋에 사용되는 사진·GIF도 계속 보관한다.

프리셋을 **불러오기** 하면 상단에 선택한 이름을 표시하고 목록에도 **선택됨**을 표시한다. 내용을 수정한 뒤 상단 **저장** 또는 **저장 후 나가기**를 누르면 다음 선택지를 제공한다. 불러온 내용과 같으면 추가 확인 없이 현재 화면을 저장한다.

- **프리셋에도 반영:** 현재 화면과 선택한 프리셋의 내용·공통 배치 연결 여부를 함께 저장한다.
- **현재 화면만 저장:** 선택한 프리셋 원본을 유지하고 현재 화면만 저장한다.
- **취소:** 저장하지 않고 편집을 계속한다.

선택한 프리셋은 임시 저장과 실제 저장 후 재진입해도 유지한다. 해당 프리셋을 삭제하면 선택을 해제한다. **현재 화면만 저장**한 뒤에는 선택 프리셋과 차이가 남으므로 다음 저장에서도 반영 여부를 묻는다.

### 여러 프리셋의 공통 배치

1. 기준으로 삼을 프리셋을 **불러오기** 한 뒤 **프리셋 → 공통 배치 만들기**를 누른다. 기존 공통 배치는 **공통 배치 편집**으로 연다.
2. **공유할 요소**에서 **현재 화면 요소**와 **공통 배치 요소** 사이로 요소를 길게 눌러 드래그한다. **추가 → / ← 제외** 버튼으로도 선택할 수 있다. 시계·날짜·배터리뿐 아니라 밝기 슬라이더·각 버튼·출퇴근 게이지·GIF도 선택할 수 있다.
3. **배치 조정**에서 선택한 요소를 이동하거나 크기·고정을 조정하고 **공통 저장**한다. 새로 만들면 현재 편집 화면과 불러온 기준 프리셋을 연결한다. 기존 공통 배치의 변경은 연결된 프리셋에 적용한다.
4. 함께 사용할 각 프리셋 카드에서 **공통 배치 사용**을 켠다. 특정 프리셋의 연결을 끄면 그 프리셋에 보관된 원래 위치·크기·고정 여부로 돌아간다.

공유하는 항목은 선택한 요소의 **위치·크기·고정 여부**, **내용 맞춤 크기·가장자리 기준·내부 여백**이다. 내용 맞춤에서는 공통 내용 크기로 그리며, 폰트마다 실제 영역의 너비는 달라질 수 있어도 지정한 가장자리 여백을 유지한다. 폰트·기본 글자색·요소별 색상·불투명도·GIF 파일·맞춤·속도·반복·게이지 방향·배경·요소의 앞뒤 순서는 각 프리셋에서 유지한다. 연결된 공통 요소는 일반 편집에서 배치 조작이 비활성화되며, **공통 배치 편집**에서 한 번만 바꾼다. 다른 속성을 편집하고 해당 프리셋에도 저장해도 공통 대상 요소의 원래 배치는 보존한다.

공통 배치를 사용하는 프리셋과 현재 화면에 선택된 요소가 없으면 **자동으로 추가**한다. 새 요소는 공통 배치에 보관한 기준 요소의 설정을 복사한다. GIF 파일·맞춤·속도·반복, 출퇴근 게이지 방향·색상 등도 함께 복사하며, 이미 있는 요소의 개별 설정은 덮지 않는다. 공통 배치를 사용하지 않는 프리셋에는 추가하지 않는다.

같은 종류가 여러 개면 번호로 대응한다. 두 번째 요소만 선택했고 대상 화면에 해당 종류가 하나도 없으면 두 번째에 해당하는 요소 하나만 추가한다. 자동 추가된 요소의 대응 번호는 저장·재진입 후에도 유지한다. 영역 밖에 놓으면 선택을 바꾸지 않는다.

**현재 편집 화면에도 사용**은 현재 디자인과 새로 저장할 프리셋의 연결 여부를 정한다. 상단 **저장**으로 현재 디자인에 적용하면 순환을 끈 상태에서도 공통 배치를 사용한다. 편집 중인 연결 상태도 임시 저장한다. 공통 배치에서 요소를 제외하거나 연결을 꺼도 자동 추가된 요소는 프리셋에 남는다. 기존 요소는 원래 배치로, 자동 추가된 요소는 처음 복사한 배치로 돌아간다. 이후 일반 요소 편집에서 제거할 수 있다. 전체 제외도 저장할 수 있다. 저장하지 않고 닫으면 공통 배치 변경을 버릴지 확인한다.

공통 기준에서 사용하는 GIF는 원본 프리셋을 삭제해도 유지한다. 현재 화면·임시 저장·프리셋·공통 기준 어디에서도 사용하지 않을 때 앱 내부 파일을 정리한다.

### 알림 패널

1. 잠금을 푼 뒤 앱의 **알림 패널 → 알림 접근 허용**에서 **Fold 스탠바이 알림 패널**을 허용한다. 자동 감시용 알림 표시 권한과 별개의 Android 설정이며, 사용자가 직접 켜야 한다.
2. 스탠바이 배경을 **오른쪽에서 왼쪽으로** 당기면 알림 패널이 손가락을 따라 들어온다. 오른쪽 화면 절반에 바깥 여백을 두고 떠 있으며, 뒤쪽 배경·요소를 실제로 흐리게 비춘다.
3. 접힌 상태에서는 **앱 이름·누적 개수**와 지우기·펼침 버튼만 표시한다. 최신 알림이 가장 최근인 앱이 위에 놓인다. 앱 이름을 누르면 최신 알림부터 제목·본문이 아래로 펼쳐진다. 다시 누르면 모든 내용이 위로 접혀 숨겨진다. 알림이 한 개뿐인 앱에도 같은 방식이 적용된다.
4. 펼친 목록 안에서 **위아래로 스와이프**해 스크롤한다. **개별 알림을 오른쪽에서 왼쪽으로** 충분히 밀면 스탠바이 기록에서 제거한다. 휴대폰 알림과 원래 앱의 읽음 상태는 바꾸지 않는다.
5. 패널을 **오른쪽으로 밀거나**, 패널 바깥을 누르거나, **×**·뒤로 가기로 닫는다. 열려 있는 동안 프리셋은 바뀌지 않는다.

앱 이름 옆 **지우기**는 그 앱의 누적 알림을 한 번에 제거한다. 상단 **모두 지우기**는 현재 패널에 표시되는 모든 앱의 기록을 제거한다. 필터로 숨겨진 기록과 버튼을 누른 뒤 새로 도착한 알림은 남긴다. 두 동작 모두 스탠바이 기록에만 적용되며, 제거한 기록은 재연결해도 다시 나타나지 않는다.

수신한 알림은 최근 500개까지 쌓인다. 같은 시스템 알림 ID가 새 내용으로 갱신돼도 이전 기록을 유지하며, Android가 여러 메시지를 묶어 전달하면 각 메시지를 분리한다. 같은 묶음의 재전달이나 내용이 그대로인 일반 알림 갱신은 중복으로 쌓지 않는다. 하위 알림이 있는 그룹 요약은 중복 표시하지 않고 이 앱의 자동 감시 알림은 제외한다.

휴대폰 알림창에서 알림이 사라져도 스탠바이 수신 기록은 남는다. 앱 재시작 후에도 기록과 제거 상태를 유지한다. 기록은 이 기능이 수신한 시점부터 쌓이며, 처음 연결할 때 Android가 현재 전달하는 알림도 가져온다. 이미 사라져 전달되지 않는 과거 내용은 소급 복원할 수 없다. 일반 알림이 같은 제목·본문으로 계속 갱신되면 중복으로 취급하며, 메시지 시각이 제공되는 경우 동일한 문장도 서로 다른 시각이면 별도로 남긴다.

앱의 **알림 패널 → 앱별 알림 규칙**에서 **선택한 앱만**을 누르고 원하는 앱을 체크한다. 카카오톡을 기본 선택으로 제시하며, 캘린더 등 원하는 앱을 검색해 추가할 수 있다. 체크하지 않은 앱과 새로 설치한 앱의 알림은 표시하지 않는다. 모두 해제하면 아무 알림도 표시하지 않는다.

**내용 설정**에서 아래 규칙을 고른다. 앱 선택을 껐다 켜도 내용 공개 설정은 유지한다. **전체 앱** 모드로 바꾸면 앱별 숨김 규칙을 제외한 모든 앱을 표시하며, 선택 목록은 보관해 다시 돌아올 수 있다. 선택·규칙은 즉시 저장하고 현재 알림에도 적용한다. 휴대폰의 기본 알림 설정은 변경하지 않는다.

| 규칙 | 스탠바이에서의 표시 |
| --- | --- |
| 숨김 | 해당 앱을 목록에서 제외 |
| 잠금 설정 따름 | 잠금 화면용 공개 내용 사용. 비공개는 공개 버전 또는 가림 안내, 숨김 알림은 제외 |
| 내용 표시 | 잠금 상태에서도 Android가 전달한 제목·본문 표시 |
| 내용 숨김 | 앱 이름·시간과 새 알림 안내만 표시 |

초기에는 시스템 UI를 숨기고 카카오톡 내용을 표시한다. 다른 앱은 잠금 설정을 따르며, 사용자가 바꾼 규칙은 다음 실행에도 유지한다. 앱 목록에는 실행 가능한 앱과 현재 알림이 있는 앱, 규칙을 저장한 앱이 나온다.

**내용 표시**는 스탠바이 앱이 추가로 가리던 처리를 해제한다. Android가 민감 정보 등을 가려 전달했거나 카카오톡에서 알림 내용을 보내지 않으면 원문을 복원할 수 없다. 수신 당시 숨긴 내용도 과거 기록에서 되살릴 수 없다. 현재 앱 규칙은 누적 목록에도 적용한다.

누적 기록은 앱 내부 파일에 AES-GCM으로 암호화하고, 키는 Android Keystore에 보관한다. 평문 기록 파일이나 알림 내용 진단 로그를 만들지 않는다. 패널에서의 제거는 해당 기록만 지우며 시스템 알림 취소·읽음·답장·앱 실행은 하지 않는다. 접근 권한이 없으면 설정 안내를, 허용 후 표시할 기록이 없으면 빈 목록 안내를 표시한다.

## 조건 판정

- **잠금:** Keyguard가 표시 중이며, 보안 잠금이 있는 기기는 인증이 필요한 상태여야 한다. 생체 인증·신뢰 기기 등으로 인증이 풀린 상태에서는 표시하지 않는다. 앱에서 잠금을 해제하지 않는다.
- **충전:** 배터리의 충전 진행률이 아니라 외부 전원 연결 여부를 사용한다. 완충·충전 대기만으로 새 진입을 만들지 않는다.
- **가로:** 잠금 화면의 화면 크기 대신 자세 센서로 양방향 가로를 판정한다. 평평하게 눕혀 자세를 판별할 수 없으면 표시하지 않는다. 각도 경계의 작은 흔들림에는 여유각을 둔다.
- **종료:** 조건 흐름을 관찰하고, 잠금 해제는 시스템 이벤트와 250ms 간격 확인을 함께 사용한다. 짧은 화면 전환 애니메이션이 적용된다.

시스템 회전 요청이 무시되는 큰 화면에서는 시계 캔버스와 힌지 좌표를 가로로 변환한다. 세로 시계 배치는 사용자에게 노출하지 않는다.

기존 `0.1.0`의 수동 시계 열기와 시스템 화면보호기 `DreamService`는 세 조건을 우회할 수 있어 `0.2.0`에서 진입을 비활성화했다. 이전 실기기 결과는 [초기 앱 검증](fold6-validation.md), [초기 화면보호기 검증](fold6-dream-validation.md)에 버전별 기록으로 남겨 두었다.

## 빌드와 설치

Android Studio에서 이 폴더를 연다. JDK 17 이상과 Android SDK Platform 36.1이 필요하다. 실제 빌드에는 JDK 21을 사용했다. SDK 경로는 `ANDROID_HOME` 또는 개발 환경별 `local.properties`에 설정한다.

```sh
./gradlew assembleDebug testValidationUnitTest lintDebug
adb devices
adb -s <기기-ID> install -r app/build/outputs/apk/debug/app-debug.apk
adb -s <기기-ID> shell am start -n dev.kwonsu.standby/.MainActivity
```

설치 패키지는 `dev.kwonsu.standby`, 표시 이름은 **Fold 스탠바이**다. APK 사본은 `output/fold-standby-0.13.0-debug.apk`에 둔다. 빌드와 기기 검사 결과는 버전별 검증 기록에서 구분한다.

기기 자동 검사는 별도 `dev.kwonsu.standby.validation` 패키지에서 실행한다. 실제 사용 앱의 데이터가 검사 도구의 설치·제거 과정에 영향받지 않도록 검사 APK를 분리했다.

```sh
./gradlew assembleValidation assembleValidationAndroidTest
adb -s <기기-ID> install -r app/build/outputs/apk/validation/app-validation.apk
adb -s <기기-ID> install -r app/build/outputs/apk/androidTest/validation/app-validation-androidTest.apk
adb -s <기기-ID> shell am instrument -w -r dev.kwonsu.standby.validation.test/androidx.test.runner.AndroidJUnitRunner
```

## 진단과 구현

```sh
python3 scripts/collect-device-evidence.py --serial <기기-ID> --output output/device-conditions
```

위 명령은 앱 진단 파일과 모델·OS 버전만 읽어 로컬에 저장한다. 화면 조작이나 전원 상태 모의 주입은 하지 않는다. USB를 빼도 앱 내부 기록은 유지된다. `run-as` 수집은 debug 빌드에서 사용한다.

`conditions_changed`에서 세 조건을 확인하고, `launch_attempt`와 같은 `attempt`의 `standby_resumed`·창 포커스·`launch_acknowledged`를 실제 화면과 함께 대조한다. 종료는 `standby_conditions_exit`와 조건 해제 기록을 대조한다.

주요 코드는 `StandbyConditionsObserver.kt`(실제 상태 관찰), `Policies.kt`(조건·안정화 정책), `ChargeMonitorService.kt`(진입), `StandbyActivity.kt`(표시·종료), `LandscapeFrame.kt`(가로 캔버스), `SceneCanvas.kt`(공통 화면), `SceneEditor.kt`(편집), `EditorViewModel.kt`·`SettingsStore.kt`(저장), `MediaRepository.kt`·`MediaLayer.kt`(선택 파일 보관·재생)다.

## 현재 제약

- Fold6의 자세 센서는 화면이 꺼졌을 때 CPU를 깨우지 않는 센서다. 화면이 꺼진 뒤 돌려도 감지하도록 **잠금·충전 중에만** CPU 유지 잠금을 사용하고, 잠금 해제·전원 해제·감시 종료 때 해제한다. 자세 센서는 충전 중에만 켠다. 장시간 전력 소모와 발열은 아직 측정하지 않았다.
- 저전력 AOD 구현이 아니다. 0.3.0은 사용자가 지정한 배치를 유지하며 장기 번인 방지 기능을 제공하지 않는다. 여러 GIF를 동시에 재생할 때의 장시간 전력·발열도 아직 측정하지 않았다.
- 야간 모드는 수동이며 조도 기반 자동 전환은 없다.
- 개인 기기용 debug 검증 단계다. 스토어 배포·심사·릴리스 서명은 포함하지 않았다.
- 네트워크나 전체 사진 보관함 접근 권한을 요구하지 않는다. 사용자가 파일 선택기로 지정한 파일만 읽는다. 진단 내보내기는 사용자가 공유 대상을 선택하는 Android 공유 창을 연다.
