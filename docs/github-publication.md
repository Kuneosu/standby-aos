# 공개 저장소 준비 검증

2026-10-29 · 소스 버전 0.13.0 · 공개 저장소 초기 커밋 준비.

## 정리한 내용

- README를 기능 소개·화면·사용 방법·빌드·제약 중심으로 다시 작성했다. 이전 상세 설명과 변경 이력은 `docs/user-guide.md`에 보존했다.
- 소개용 생성 배너 1장과 기존 Fold6 검사 캡처 4장을 추가했다. 실제 화면과 콘셉트 이미지를 구분하고 출처를 기록했다.
- 빌드 결과·원본 기기 기록·로컬 설정·서명키·글꼴 다운로드 묶음을 Git 대상에서 제외했다. 검사에 필요한 작은 PNG·GIF fixture는 포함했다.
- 선택 글꼴이 없는 경우 기본 글꼴로 표시하도록 변경했다. 글꼴 선택값과 기존 개인 개발 환경의 글꼴 원본 3개는 보존했다.
- 버전별 검증 문서의 비공개 산출물 링크를 로컬 전용 경로 안내로 정리했다.

## 이번에 실행한 검증

Git에 포함할 파일만 별도 임시 폴더에 복사했다. 원본 프로젝트의 빌드 폴더·설정 파일·선택 글꼴을 복사하지 않은 상태에서 실행했다. JDK·Android SDK·Gradle 의존성 캐시는 개발 환경에 설치된 것을 사용했다.

```sh
./gradlew assembleDebug testValidationUnitTest lintDebug --console=plain
```

| 항목 | 결과 |
| --- | --- |
| 공개 소스의 Debug APK 빌드 | 통과 |
| 단위 검사 | 101개 통과, 실패·오류·건너뜀 0 |
| Debug Lint | 오류 0개, 기존 경고 14개 |
| 공개 소스 APK 내 선택 글꼴 바이너리 | 없음 |
| 기존 로컬 글꼴 3개 | 변경 전후 SHA-256 일치 |
| 문서·이미지의 로컬 링크 | Git 포함 파일을 기준으로 확인 |
| 업로드 대상의 키·개인 절대경로·기기 ID | 정해진 문자열 패턴 검사에서 미검출 |

문자열 패턴 검사는 저장소 준비 확인이며 전문 보안 감사를 뜻하지 않는다. 상세 빌드 로그와 검사 집계는 `output/github-publication/`에 로컬로 보관한다.

## 이번에 실행하지 않은 검증

기기 설치·기기 계측 검사·잠금 및 충전 조건 조작·장시간 사용은 실행하지 않았다. 공개 준비 과정에서 바뀐 글꼴 선택·대체 처리의 실기기 동작은 이번 검사 범위에 포함하지 않는다. 앞선 [0.13.0 기능 검증](work-shift-edit-0.13.0.md)의 실기기 결과와 구분한다.
