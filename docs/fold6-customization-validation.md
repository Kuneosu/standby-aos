# Fold6 화면 꾸미기 검증 — 0.3.0

검증일: 2026-10-23 / 기기: Galaxy Z Fold6 `SM-F956N` / Android 16 / One UI 시스템 값 `80500`.

## 결과

제공된 3종 폰트, 글자색, 단색·프리셋·사진 배경, GIF 배치·속도·반복, 화면 요소 편집과 저장을 구현했다. 빌드와 단위 검사 29개, 실제 Fold6에서 실행한 기기 검사 12개가 통과했다. 사용 앱의 파일 선택기 가져오기, 저장 후 재실행 복원, 실제 잠금·충전·가로 상태에서 시계와 GIF 표시도 확인했다.

자동 진입 첫 시험에서는 디자인 로딩 중 빈 자식을 측정하는 오류로 앱이 종료됐다. 가로 프레임에 항상 존재하는 컨테이너를 두어 수정하고, 빈 상태 → 저장된 디자인 → 빈 상태의 회귀 검사를 추가했다. 수정한 APK를 다시 설치한 뒤 사용자가 “시계와 GIF가 나오고 잠금 해제하면 닫혀요”라고 확인했다.

## 제공 기능

| 기능 | 내용 |
| --- | --- |
| 폰트 | 기본, 이사만루 Medium, 메이플스토리 Light, 메모먼트꾹꾹체. 사용자 제공 TTF를 앱에 포함 |
| 색상 | 전체 글자색과 요소별 색상, 팔레트와 6자리 HEX. 야간 모드는 붉은색 우선 |
| 배경 | 단색, 오로라·노을·심해·샌드 프리셋, 사용자 사진 |
| 사진 | 채우기·맞추기·늘이기, 0.5~3배 확대, 좌우·상하 이동, 가로·세로 비율, 밝기 조정 |
| GIF | 여러 개 추가, 끌어 이동·모서리 크기 변경·슬라이더 조정, 맞춤·투명도, 개별 0.25~3배 속도 및 반복 |
| GIF 1회 재생 | 마지막 프레임 유지. 시계를 다시 열거나 속도·반복을 바꾸면 처음부터 재생 |
| 요소 | 시계·날짜·배터리·야간 버튼·진단 버튼·닫기 버튼·GIF 추가, 제거, 앞뒤 순서. 최대 20개 |
| 저장 | 편집 중 임시 저장, 저장 버튼으로 적용, 나갈 때 저장·버리기·계속 편집 |
| 화면 비율 | 커버·16:9·내부 화면 미리보기. 실제 화면에서는 동일한 위치·크기 비율 적용 |

사진과 GIF는 파일 선택기로 고른 파일만 내부 저장소로 복사한다. 원본 위치가 바뀌거나 원본이 없어져도 복사본을 사용한다. 파일당 20MB, GIF 약 210만 화소 제한을 적용하며 사진은 긴 변 최대 2048px로 디코딩한다.

## 시험 자료와 설치 상태

초기 기기 검사를 사용 앱 패키지에 연결해 실행했을 때 Gradle의 기기 검사 종료 정리가 앱을 제거하면서 기존 앱 데이터가 초기화됐다. 이를 사용자에게 알렸고, 이후 검사 패키지를 `dev.kwonsu.standby.validation`으로 분리했다. 현재 사용 앱은 `0.3.0`을 설치하고 다른 앱 위 표시·알림 권한과 자동 감시를 복구했다. 이전 야간 모드 값은 복원 근거가 없어 기본값이다.

최종 정리에서는 직접 만든 사진·GIF 원본을 검사 파일과 바이트 비교한 뒤 제거했다. 사용 앱은 기본 폰트·기본 단색·기본 6요소로 저장했고, 시험용 사진 참조와 앱 내부 복사본까지 제거했다. 설정 재실행을 확인했으며 자동 감시는 켜 두었다. 검사 전용 패키지와 이전 테스트 패키지도 제거했다. 정리 결과 (`output/device-customization/cleanup.json`, 로컬 전용), 최종 디자인 (`output/device-customization/cleaned-scene.json`, 로컬 전용).

## 남은 검증 범위

- 새 자유 배치로 내부 화면·반접힘을 장시간 사용하는 검사는 하지 않았다. 이전 버전의 힌지별 자동 배치 대신 사용자가 정한 전체 캔버스의 비율 배치를 사용한다.
- 여러 GIF 동시 재생의 장기 메모리·전력·발열, 장시간 번인은 측정하지 않았다.
- 이번 최종 수정본에서 USB 분리·재연결 시나리오를 다시 반복하지 않았다. 기존 자동 조건 정책의 단위 검사와 [0.2.0 실제 전원 검사](fold6-conditions-validation.md)는 통과했다.
- 별도 에뮬레이터, 다른 제조사 기기, 스토어 배포·릴리스 서명 검증은 포함하지 않는다.
