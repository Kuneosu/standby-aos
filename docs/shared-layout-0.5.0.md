# 공통 배치 — 0.5.0

2026-10-26 / Galaxy Z Fold6 `SM-F956N` / Android 16.

## 구현과 보존 범위

기존에는 각 프리셋이 독립적인 화면 전체를 저장했다. 이제 시계·날짜·배터리·밝기 슬라이더의 위치·크기·고정 여부를 별도의 공통 배치로 저장하고, 연결한 화면을 표시할 때만 합성한다. 각 프리셋의 원래 장면을 공통 배치로 덮지 않는다.

| 공통으로 관리 | 프리셋별로 유지 |
| --- | --- |
| 네 종류 요소의 x·y·너비·높이·위치 고정 | 폰트·기본 글자색·요소별 색상·불투명도 |
| 같은 종류가 여러 개면 같은 종류 안의 순서로 대응 | GIF 파일·배치·재생 설정, 배경 설정, 요소 앞뒤 순서 |

- 연결·해제는 프리셋의 연결 여부만 바꾼다. 해제하면 원래 배치로 표시한다.
- 연결 중에는 일반 편집기에서 공통 대상의 배치 조작을 막고, 별도 공통 편집기에서 수정한다. 스타일 편집 때 표시된 공통 좌표가 원본에 섞이지 않도록 UI와 저장 단계에서 보호한다.
- 연결된 프리셋을 덮어써도 공통 대상의 기존 배치를 보존하고 개별 스타일·GIF·배경을 갱신한다.
- 공통 편집기에서는 GIF·배경을 확인용으로 표시하며, 공통 대상만 이동·크기 조정할 수 있다. 잠금과 중앙 정렬 가이드를 지원한다.
- 저장 전 공통 편집은 화면 재생성 후 유지하며, 닫을 때 변경을 버릴 수 있다.
- 기존 프리셋은 연결하지 않은 상태로 읽는다. 기존 `scene_v1`과 개별 프리셋 장면을 유지하고, `presets_v1` 안에 선택적인 공통 배치·연결 필드를 추가했다.
- 현재 디자인과 임시 편집에도 연결 여부를 별도로 저장한다. 순환을 끈 현재 디자인에서도 공통 배치를 사용할 수 있다.
- 공통 배치는 미디어를 소유하지 않는다. 기존 디자인·임시 편집·모든 저장 프리셋의 미디어 보존 규칙을 유지한다.

## 검사

단위 검사 45개를 통과했다. 추가 8개는 공유 필드 제한, 원본과 연결 해제, 연결 대상에만 전파, 다른 ID·같은 종류의 복수 요소 대응, 누락 요소 처리, GIF·버튼 제외, 덮어쓰기 보호, 삭제·추가 시 배치 보존, 공통 편집 미리보기와 좌표 정규화를 검증한다.

실기기 검사는 별도 `dev.kwonsu.standby.validation`에서 실행했다. 추가한 검사는 다음을 다룬다.

1. 이전 프리셋 형식의 기본 연결 해제, 새 형식 저장·디스크 재오픈, 순환 중 실제 선택 결과, 원본 장면 보존, 현재 디자인·임시 편집의 연결 상태.
2. 실제 편집기에서 공통 배치 생성, 두 프리셋 연결, 공통 이동·크기·고정 저장, 저장 후 재진입, 개별 폰트·색상·GIF 배치 수정 및 덮어쓰기, 연결 해제 후 원래 배치와 개별 스타일 유지.
3. 저장 전 공통 편집의 Activity 재생성 복원과 변경 버리기.

첫 전체 실행은 26개 중 25개가 통과했다. 남은 검사는 GIF를 포함한 프리셋을 불러오면 기존 편집기가 요소 탭으로 이동하는 것을 반영하지 않아, 프리셋 탭의 버튼을 찾지 못했다. 프리셋 탭으로 이동하는 실제 사용 단계를 검사에 추가했다. 이 수정으로 제품 코드는 바꾸지 않았다.

최종 재검증은 공통 편집에서의 실제 드래그와 GIF 이동 차단까지 포함해 통과했다. **고유 시나리오 26개의 최종 상태가 모두 통과**다. 최초에 통과한 25개와 남은 1개의 최종 재실행 결과를 합친 수치이며, 새 전체 실행 26개로 표시한 것은 아니다.

## 설치와 사용자 데이터 보존

사용 앱 `dev.kwonsu.standby`를 삭제하지 않고 `0.4.1`에서 `0.5.0`(versionCode 7)으로 업데이트했다. 설정·미디어 6개 파일의 SHA-256이 검사 전·설치 직전·설치 직후 모두 같았다. 기존 프리셋의 공통 연결은 기본값인 꺼짐으로 유지하며, 사용자가 선택한 것만 연결한다.

검사 전용 앱 두 개를 제거하고, 기존에 켜져 있던 자동 감시를 다시 켰다. `ChargeMonitorService`의 `isForeground=true`를 확인했다.
