# 자동 퇴근과 예정 시각 기준 대기 — 0.11.0

2026-10-28 / versionCode 22.

100%가 되는 예정 퇴근 시각에 자동으로 퇴근하고, 전체 화면 폭죽을 재생한 뒤 출퇴근 게이지만 숨긴다. 수동 퇴근 버튼을 제거했으며, 다시 출근할 수 있는 시각은 예정 퇴근 시각에서 12시간 후로 계산한다.

## 변경 동작

- 17시에 100%가 됐다면 다음 날 05시부터 출근할 수 있다. 폭죽 재생 종료 시각이나 화면을 다시 연 시각 때문에 대기가 늘어나지 않는다.
- 화면이 없는 동안 완료됐어도 출근·예정 퇴근 시각을 보존한다. 다음 표시 때 자동 퇴근 시각을 예정 시각으로 저장한다.
- 예정 시각에서 12시간 이내에 다시 열면 미재생 폭죽을 한 번 표시하고 남은 시간만 게이지를 숨긴다.
- 이미 12시간이 지났다면 과거 폭죽을 생략하고 바로 출근 버튼을 표시한다.
- 폭죽을 끝까지 재생한 경우만 재생 완료를 저장한다. 화면 재생성·일시정지로 중단되면 대기 기간 내에 다시 재생한다.
- 시계·날짜·배터리·배경·GIF와 스탠바이 진입·종료 조건은 근무 대기와 분리한다.

## 이전 기록 전환

현재 실사용 0.10.2에서 오늘 수동 퇴근을 누른 기록은 출근 시각과 예정 퇴근 시각이 모두 0이며, 버튼을 누른 시각만 남아 있었다. 기존 수동 퇴근 구현이 두 시각을 지우기 때문에 정확한 이전 마감을 복원할 수 없다.

이 형태의 구버전 기록은 0.11.0에서 처음 읽을 때 대기를 한 번 해제한다. 진행 중인 근무와 마감 시각이 남은 기록은 보존하며, 다른 설정·프리셋·미디어는 변경하지 않는다. 새로운 자동 퇴근 기록은 출근·예정 퇴근 시각을 유지하므로 같은 전환 대상이 되지 않는다.

## 검증

| 구분 | 결과 |
| --- | --- |
| Debug·Validation·계측 APK 빌드 | 통과 |
| 단위 검사 | 92개 통과 |
| Debug·Validation Lint | 각각 오류 0개, 기존 경고 14개 |
| Fold6 별도 검사 앱 | 관련 14개 통과 |
| 실사용 데이터 보존 | 설정·근무 기록·미디어 7개 파일 해시 일치 |
| 검사 앱 정리 | 검사 패키지 2개 제거 |
| 실사용 자동 감시·알림 연결 | foreground 실행·서비스 연결 확인 |

실기기 검사는 출근 다이얼, 가로·세로 게이지, 실제 프레임 변화가 있는 전체 화면 폭죽, 자동 숨김, 재진입, Activity 일시정지·재개, 12시간 직전·정각, 오래된 폭죽 생략, 이전 기록 전환 및 디스크 재개방을 포함한다. 별도 시나리오에서 기기 시계를 바꾸지 않고 검사 근무의 마감을 수 초 뒤로 두어 실제 시간 갱신에 따른 자동 퇴근도 확인했다.

12시간 경계는 검사 앱에 지정한 시간으로 확인했다. 실제 12시간 대기나 하루 연속 사용, 잠금·충전·자세별 전체 진입·종료 조합은 다시 검사하지 않았다. 설치 후에는 실제 잠금·충전·가로 조건에서 자동 진입 한 번을 추가 확인했다. 검사는 실사용 앱과 분리된 `dev.kwonsu.standby.validation`에서 수행했다.

## 설치 상태와 산출물

사용자 승인 후 Fold6에 **0.11.0 / versionCode 22 설치 완료**. 앱 화면의 자동 스탠바이 버튼으로 감시를 복구하고 foreground 실행·알림 서비스 연결을 확인했다.

- 설치 직전·설치 직후·자동 감시 복구 후 설정·근무 기록·미디어 7개 파일의 해시가 모두 같았다.
- 이후 실제 가로·충전 상태에서 화면을 잠그자 스탠바이가 자동 진입했다. Activity 활성화·창 포커스·자동 실행 확인 기록을 대조했다.
- 구버전 수동 퇴근 기록의 `checked_out_at`이 0으로 전환됐고, 실제 스탠바이에 시계·날짜·배터리와 **출근 버튼**이 표시됐다. 새 출근 기록은 만들지 않았다.
- 자동 진입 뒤 설정 파일에서 바뀐 키는 프리셋 순환용 `cycle_cursor`·`cycle_entry` 두 개뿐이다. 사용자 설정·프리셋 내용·미디어는 보존됐다. 근무 파일의 변경은 요청한 이전 대기 해제다.
- 검증 종료 시 자동 감시와 알림 서비스가 정상이며, 스탠바이 화면을 유지했다.
