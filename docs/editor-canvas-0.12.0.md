# 편집 캔버스 개선 — 0.12.0

2026-10-28 / versionCode 23.

시계의 글자 크기와 요소 박스 크기를 따로 조절하고, 오른쪽 정렬과 화면 가장자리 맞춤을 제공한다. 겹친 요소는 목록에서 선택하며, 실제 기기의 가로 화면 크기로 보면서 직접 편집한다.

## 사용 흐름

1. **화면 꾸미기 → 전체 화면 편집**을 연다. 현재 기기의 가로 화면 전체를 사용하며 시스템 표시줄을 숨긴다.
2. **요소 목록**에서 편집할 요소를 고른다. 다른 요소에 가려져 있어도 선택 테두리와 네 모서리 손잡이는 가장 위에 표시한다. 내용의 앞뒤 순서는 유지한다.
3. 드래그로 이동하거나 네 모서리에서 크기를 조절한다. 오른쪽 끝에 붙인 요소의 왼쪽 손잡이를 당기면 오른쪽 끝이 유지된다.
4. **조정**에서 글자 정렬·자동 크기·직접 지정 크기와 요소 위치·크기를 바꾼다. **오른쪽 정렬 + 오른쪽 끝**으로 박스 안쪽의 큰 여백 없이 오른쪽에 배치한다.
5. **화면만 보기**로 테두리와 도구 막대를 숨긴다. **편집 도구**로 다시 편집하며, 도구 막대는 위아래로 옮길 수 있다.
6. **저장**은 기존 현재 화면·선택 프리셋 저장 흐름을 사용한다. **닫기**는 편집 내용을 유지하고 일반 편집 화면으로 돌아간다.

시계·날짜·배터리에 글자 정렬과 크기 설정을 제공한다. 직접 지정한 글자 크기는 화면 높이에 대한 비율로 보관하며, 요소 너비를 넓혀도 유지한다. 글자가 영역보다 크면 잘리지 않도록 축소한다. 글꼴 자체의 작은 좌우 여백은 남을 수 있다. 기존 저장 데이터에는 가운데 정렬·자동 크기를 적용한다.

공통 배치도 전체 화면 편집을 지원한다. 공통 요소의 위치·크기·고정 여부는 공통 편집에서 바꾸고, 글자 크기·정렬은 각 프리셋에 유지한다. 기존 위치 고정, 중앙 정렬 가이드, 임시 저장과 편집 취소 흐름을 유지한다.

실제 Fold6에서 다음 범위를 확인했다.

- 네 글꼴의 오른쪽 글자 배치와 실제 픽셀 여백, 요소 너비를 바꾼 뒤 지정한 글자 크기 유지.
- 완전히 겹친 요소를 목록에서 선택하고 해당 요소만 이동·크기 조절. 내용의 앞뒤 순서 보존.
- 실제 Activity의 가로 방향 요청과 전체 화면 크기 일치, 글자 크기·정렬·가장자리 배치 조절.
- 왼쪽 모서리에서 크기를 키운 뒤 오른쪽 끝 유지, 편집 중 임시 저장과 화면 재생성.
- 현재 화면·선택 프리셋 저장, Activity 종료·재진입 후 DataStore 재조회.
- 공통 배치의 전체 화면 편집·저장과 각 프리셋의 글자 크기·정렬·색상 보존.
- 사진·GIF 재생, 글꼴·색상·요소 제거, 위치 고정, 정렬 가이드, 프리셋 생성·선택·순환, 공통 요소 자동 추가의 기존 회귀.

첫 실행은 회전된 목록의 불필요한 자동 스크롤에서 멈춰 검사 앱을 종료했다. 해당 호출을 수정했고, 재개 후에는 가로 스크롤 안에 숨은 가장자리 버튼 때문에 검사 터치가 패널 밖으로 향하는 문제를 확인했다. 배치 버튼 세 개가 패널 안에 모두 보이도록 개선했다. 프리셋 생성 검사에서 한 차례 저장 대기가 초과됐으나 개별 재검사와 마지막 전체 실행 모두 통과했다. 최종 실행은 30개 전부 성공했으며, 첫 실패·진단 로그도 보존했다.

검사는 별도 `dev.kwonsu.standby.validation` 패키지에서 수행했다. 검사 후 두 검사 패키지를 제거하고 실사용 설정 화면으로 돌아왔다. 실사용 설정·근무 기록·미디어는 검사 시작·연결 재개·종료 시점에 동일했다.

이후 사용자의 설치 요청에 따라 검증한 APK와 SHA-256이 일치하는 0.12.0을 `adb install -r`로 업데이트했다. 기기 패키지 정보와 앱 설정 화면에서 0.12.0 / versionCode 23을 확인했다. 설치 직후와 자동 감시 재시작 후에도 기존 설정·근무 기록·미디어 7개 파일의 해시가 모두 일치했다. 업데이트로 종료된 자동 감시는 설치 전 상태대로 다시 켰으며, foreground 실행과 알림 서비스 연결을 확인했다. 설치 후 잠금·충전·자세 조건에 따른 자동 진입 검사는 별도로 반복하지 않았다.
