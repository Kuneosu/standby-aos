# 내부 여백·시계 가림 수정 — 0.12.2

2026-10-28 / versionCode 25.

좌우·위아래 여백을 화면 끝에서 컴포넌트를 떨어뜨리는 간격으로 잘못 구현했던 것을 수정했다. 이제 컴포넌트 테두리와 내용 사이에 적용한다. 내용 맞춤 시 시계 모서리가 잘려 보이던 문제는 선택 테두리와 손잡이가 글자를 덮는 것으로 재현했다.

## 동작

- **좌우 내부 여백 (%)**은 컴포넌트 너비 기준으로 왼쪽·오른쪽에 각각 적용한다. **위아래 내부 여백 (%)**은 높이 기준으로 위·아래에 각각 적용한다. 범위는 0~40%다.
- **내용에 맞춘 영역**은 실제 글자 크기와 내부 여백을 합쳐 계산한다. 여백을 늘려도 글자 크기를 유지하며 외곽 영역이 커진다. 화면을 넘을 때만 전체가 들어오도록 줄인다.
- **오른쪽 끝·왼쪽 끝·위쪽 끝·아래쪽 끝**은 외곽 테두리를 화면 끝에 붙인다. 자유 배치에도 내부 여백이 적용된다.
- 기존 고정 크기 영역은 영역 크기를 유지하고 내부 공간을 줄인다. 글자 외에 GIF·버튼·슬라이더·게이지도 같은 내부 여백을 적용한다.
- 선택 테두리와 손잡이 표시는 글자 영역 바깥에 그린다. 기존 모서리 터치 범위를 유지하며 화면 밖으로 나가는 표시 부분은 화면 끝에서 잘린다.
- 공통 배치와 프리셋에 내부 여백을 보관한다. 0.12.1의 여백 숫자는 그대로 읽되 내부 비율로 해석한다. 이후 저장은 별도의 내부 여백 필드를 사용한다. 이전 버전의 외부 간격은 유지하지 않는다.

예를 들어 너비 200인 컴포넌트의 좌우 여백을 5%로 정하면 왼쪽·오른쪽 내부에 각각 10의 간격을 확보한다. 내용 맞춤 모드에서는 이 비율과 원래 글자 크기를 만족하도록 컴포넌트 전체 너비가 결정된다.
