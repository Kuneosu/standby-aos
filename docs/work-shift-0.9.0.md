# 출퇴근 게이지 — 0.9.0

2026-10-26 / versionCode 15.

게임 HP 바 모양의 출퇴근 요소를 추가했다. **화면 꾸미기 → 요소 → + 출퇴근 게이지**에서 배치하고 가로·세로 방향을 고른 뒤 저장한다. 기존 개인 디자인·프리셋에 자동으로 추가하지 않는다.

## 동작

- 처음에는 **출근** 버튼을 표시한다. 누르면 화면을 채우는 시각 다이얼을 열어 당일의 실제 출근 시각을 선택한다. 버튼을 늦게 눌러도 선택한 시각으로 계산한다. 취소하면 출근 기록을 만들지 않는다.
- 퇴근 예정 시각은 **선택한 출근 시각 + 9시간**과 **출근 당일 17시** 중 더 늦은 시각이다. 07:00·08:00 → 17:00, 08:01 → 17:01, 09:30 → 18:30. 미래 시각이면 0%로 기다리고, 이미 종료 시각이 지났으면 즉시 완료 상태가 된다.
- 가로는 왼쪽부터, 세로는 아래부터 채운다. 예정 시각 직전까지 최대 99%를 표시한다. 100%가 되면 약 4.2초 동안 전체 화면 폭죽을 한 번 재생한다. 가로는 옆, 세로는 아래에 **퇴근** 버튼을 표시한다.
- 퇴근 버튼을 누르면 게이지·출근 버튼이 모두 숨겨진다. **실제 퇴근 버튼을 누른 시각부터 12시간**이 지나면 출근 버튼이 다시 나온다.
- 출근 기록·예정 시각·퇴근 기록·폭죽 재생 여부를 별도 DataStore에 저장한다. 프리셋 전환과 앱 재시작 뒤에도 이어지며 여러 게이지가 같은 근무 상태를 표시한다.
- 게이지가 표시되지 않는 동안 완료되면 다음 표시 시점에 폭죽을 한 번 재생한다. 편집기의 65%는 모양 미리보기이며 실제 근무 기록을 바꾸지 않는다. 출퇴근 요소는 공통 배치 대상이 아니다.

## 검증 결과

- Debug·Validation·계측 APK 빌드 통과. 단위 검사 **87개 통과**, 그중 신규 출퇴근 규칙 11개.
- Debug·Validation Lint 각각 **오류 0개, 기존 경고 14개**.
- Galaxy Z Fold6(Android 16)의 별도 검사 앱에서 **17개 고유 검사 통과**: 출퇴근 저장 2개, 출퇴근 UI 4개, 편집기 1개, 기존 알림 패널 7개, 기존 밝기·배치 3개.
- 10시 시점에 다이얼로 08:00을 실제 터치 선택하고 **17:00 예정 / 22%**로 저장되는 것 확인. 취소, 회전된 가로 캔버스에서 다이얼·확정 버튼 터치, 두 방향의 실제 픽셀 채움도 확인.
- 종료 1ms 전 99%·퇴근 버튼 없음, 종료 시 100%·전체 화면 폭죽·퇴근 버튼, 화면 재생성 후 폭죽 중복 없음, 퇴근 후 12시간 직전 숨김·정각 복귀 확인. 디스크를 닫고 재개방하여 저장 복원과 동시 중복 입력 차단 확인.
- 최초 기기 검사는 16/17 통과했다. 다이얼 숫자가 `Text` 대신 `ContentDescription`으로 제공되는 테스트 선택자를 수정했고 출퇴근 UI 4개를 모두 재검사하여 통과했다. 화면에서 발견한 다이얼 제목 대비도 수정하고 최종 이미지로 확인했다.

시간 경계는 검사 앱에 주입한 시각으로 검증했다. 기기 시스템 시계는 변경하지 않았으며 **실제 9시간·12시간의 장시간 대기는 수행하지 않았다**. 이번 변경과 무관한 잠금·충전·자세 감지 조건 전체를 다시 실행한 결과는 아니다.

## 설치와 데이터 보존

**2026-10-27 사용 앱 0.9.0 / versionCode 15 설치 완료.** 별도 검사 앱·계측 앱 2개를 제거하고 알림 수신 재연결을 확인했다. 설치 후 잠금을 해제하고 자동 감시를 다시 켰으며, foreground 서비스 실행과 알림 수신 연결을 확인했다.

검사 전후 기존 설정·사진·GIF **6개 파일의 기기 내부 SHA-256이 동일**하다. 자동 승인 검토에서 원본 백업 복사를 차단하여 개인 설정·미디어·암호화 알림 기록은 내보내지 않았다. 개인 알림 내용을 열거나 수집하지 않았으며, 예시 화면은 검사 앱의 합성 상태만 사용했다. 2026-10-27 설치 직전과 직후에도 같은 6개 파일의 해시가 모두 동일함을 확인했다.
