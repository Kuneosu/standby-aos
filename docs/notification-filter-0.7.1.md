# 선택한 앱만 표시 — 0.7.1

2026-10-26 / versionCode 10.

## 사용법

**앱 → 알림 패널 → 앱별 알림 규칙 → 선택한 앱만**에서 원하는 앱을 체크한다. 앱 검색을 지원한다. 카카오톡·캘린더 등 사용자가 고른 앱의 알림만 표시하며, 선택하지 않은 앱과 새 앱은 제외한다.

- 선택을 모두 해제하면 알림을 표시하지 않는다.
- **내용 설정**에서 내용 표시·내용 숨김·잠금 설정 따름을 선택한다. 체크를 껐다 켜도 이 값은 유지한다.
- **숨김**을 고르면 해당 앱을 선택 목록에서도 뺀다. 이전에 숨긴 앱을 다시 체크하면 잠금 설정 따름으로 활성화한다.
- 선택하지 않은 앱에서 내용 규칙을 고르면 해당 앱도 선택 목록에 넣는다.
- **전체 앱** 모드는 기존 앱별 규칙을 적용하며, 선택 목록을 지우지 않는다.
- 설정은 스탠바이 화면에만 적용하고 즉시 저장한다. Android와 원래 앱에서 전달하지 않은 내용은 복원할 수 없다.

## 저장과 검증

기존 `notification_rules_v1` JSON에 `selectedOnly`와 `selectedApps`를 추가했다. 이전 0.7.0 규칙은 그대로 읽고, 업데이트만으로 전체·선택 모드를 자동 전환하지 않는다. 선택 목록이 없는 이전 설정에서는 카카오톡을 기본 선택으로 제시한다. 선택 모드인데 목록이 없는 잘못된 저장값은 빈 목록으로 처리한다.

단위 검사 64개가 통과했다. 추가 범위는 선택 밖 앱 제외, 새 앱 제외, 선택 해제·복원 시 내용 설정 보존, 전체 모드 복귀, 빈 목록, 숨긴 앱 재선택과 내용 규칙 변경이다. Debug·Validation·계측 APK 빌드를 완료했고, Lint는 각각 오류 0개·기존 경고 14개다.

Galaxy Z Fold6 `SM-F956N`에서 앱 선택·모드 전환·검색·저장·재진입, 저장 파일 재오픈과 기존 디자인 보존, Android 알림 내용 처리, 패널 조작 등 관련 시나리오 **11개를 15.43초에 모두 통과**했다. 기존 편집기 전체 시나리오를 다시 실행하는 범위는 아니다.

## 설치와 적용

사용 앱을 삭제하지 않고 0.7.0에서 0.7.1로 업데이트했다. 기존 설정·미디어 6개 파일의 SHA-256이 검사 전·설치 직전·직후 일치했다. 이후 사용자가 요청한 **선택한 앱만** 모드를 실제 설정 화면에서 켰으며, 이 단계에서 알림 규칙 저장값만 의도적으로 변경했다.

설치된 앱의 UI에서 선택 모드·선택 개수 1개·카카오톡 체크·내용 표시·시스템 UI 미선택을 확인했다. 카카오톡만 선택해 두었으며, 다른 앱은 사용자가 검색해서 추가할 수 있도록 설정 화면을 열어 두었다. 검사 패키지 두 개를 제거하고 자동 스탠바이 감시와 기존 알림 리스너 연결을 복구했다.

카카오톡 원문 표시와 시스템 UI 숨김은 직전 0.7.0에서 사용자가 실제 확인했다. 이번 0.7.1의 선택 필터는 위 자동 검사와 설치 앱의 설정 확인으로 검증했으며, 개인 알림 내용·화면은 수집하지 않았다.
