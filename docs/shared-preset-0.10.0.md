# 공통 배치 선택·프리셋 저장 개선 — 0.10.0

2026-10-27 / versionCode 19.

## 공통 배치

공유할 요소를 고정된 네 종류에서 현재 화면에 배치된 모든 종류로 확장했다. 시계·날짜·배터리·밝기 슬라이더뿐 아니라 출퇴근 게이지·GIF·야간/진단/닫기 버튼도 선택할 수 있다.

- **프리셋 → 공통 배치 만들기/편집 → 공유할 요소**에서 현재 화면 요소와 공통 배치 요소를 나란히 표시한다.
- 요소를 길게 눌러 반대쪽 영역으로 드래그하거나 **추가 → / ← 제외**를 누른다. 영역 밖에 놓으면 선택을 유지한다. 각 목록은 따로 스크롤할 수 있다.
- **배치 조정**에서 선택한 요소의 위치·크기·고정 여부를 편집한다. 다른 속성은 각 프리셋에 남는다. GIF의 파일·재생 속도·반복, 게이지 방향·색상도 공유하지 않는다.
- 같은 종류가 여러 개면 번호로 대응한다. 두 번째 요소만 선택해도 두 번째끼리 연결한다. 공통 요소가 현재 화면에 없으면 별도 문구를 표시하며, 다른 프리셋에 필요한 선택을 그대로 유지할 수 있다.
- 공통 배치에서 제외해도 화면 요소를 삭제하지 않는다. 전체 제외도 저장할 수 있다. 프리셋에 없는 요소를 자동으로 추가하지 않는다.
- 저장 전 변경은 화면 재생성에도 유지한다. 닫을 때 변경을 버릴지 확인한다. 기존 공통 배치에 저장된 선택과 각 프리셋의 원래 배치를 보존한다.

## 프리셋 저장

불러온 프리셋의 이름을 편집기 상단에 표시하고 목록에 **선택됨**을 표시한다. 내용을 변경한 뒤 **저장** 또는 **저장 후 나가기**를 누르면 세 가지 선택지를 제공한다.

| 선택 | 저장 범위 |
| --- | --- |
| 프리셋에도 반영 | 현재 화면과 선택한 프리셋의 내용·공통 배치 연결 여부를 함께 저장 |
| 현재 화면만 저장 | 선택한 프리셋 원본을 유지하고 현재 화면만 저장 |
| 취소 | 저장하지 않고 편집을 계속함 |

불러온 프리셋과 내용이 같으면 추가 확인 없이 현재 화면을 저장한다. 선택 상태는 임시 저장·실제 저장 후 재진입에도 유지하며, 선택한 프리셋이 삭제되면 해제한다. 현재 화면만 저장한 경우에는 선택 프리셋과 차이가 남으므로 다음 저장에서도 반영 여부를 묻는다.

현재 화면과 프리셋은 DataStore의 한 번의 편집에서 함께 저장한다. 저장 대상이 사라졌으면 프리셋 반영을 실패 처리하고 현재 화면만 먼저 저장하지 않는다. 다른 프리셋·순환 목록·공통 배치는 유지한다.

## 검증

- Debug·Validation·계측 APK 빌드 통과. 단위 검사 **88개 통과**.
- Debug·Validation Lint 각각 오류 0개·기존 경고 14개.
- Galaxy Z Fold6(Android 16)의 별도 검사 앱에서 관련 고유 **14개 검사 통과**.
- 최초 실행에서 기존·저장 관련 12개가 통과했다. 새 드래그 검사 클래스는 Kotlin 검사 함수의 반환형이 JUnit 규칙과 달라 초기화에 실패했다. 반환형을 수정한 뒤 해당 클래스의 두 검사를 실행하여 모두 통과했다. 최초 기록도 보관한다.
- 실제 길게 누르기·드래그로 두 영역 사이의 추가·제외, 영역 밖에 놓기, 버튼으로 선택, 두 번째 시계만 선택, 저장·재진입을 확인했다.
- 현재 화면에 없는 공통 요소 표시, 전체 제외, 변경 버리기, 화면 재생성 중 선택 유지, 기존 프리셋 원본 보존을 확인했다.
- 저장 팝업의 취소·현재 화면만 저장·프리셋 반영, 팝업이 열린 상태의 화면 재생성, 저장 후 재진입, 저장 후 나가기를 확인했다.
- 저장소를 닫고 다시 열어 선택 프리셋·공통 요소·빈 공통 배치를 확인했다. 삭제된 저장 대상에 대한 실패 처리와 다른 프리셋·순환 목록 보존도 확인했다.
- 기존 공통 배치 연결·해제·위치 편집·스타일 변경, 연속 편집·임시 저장·저장·취소와 사진/GIF 재생 검사를 통과했다.
- 공통 배치 선택 화면과 프리셋 저장 팝업을 실제 기기에서 캡처해 확인했다. 모든 화면 크기·접힘 상태와 장시간 동작을 재검사한 결과는 아니다.

## 설치와 보존

**2026-10-27 사용 앱 0.10.0 / versionCode 19 설치 완료.** 설치 후 자동 감시를 다시 켜고 foreground 서비스 실행과 알림 수신 연결을 확인했다.

별도 검사 전후 기존 설정·근무 기록·사진·GIF **7개 파일**의 기기 내부 SHA-256이 같다. 사용 앱 업데이트 직전·직후와 자동 감시 복구 후에도 7개 파일의 해시가 동일하다. 개인 파일 내용을 내보내지 않았다. 검사 앱 2개는 제거했다. 0.10.0 설치 후 잠금·충전·자세 변경에 따른 자동 진입·종료와 장시간 동작은 이번에 다시 검사하지 않았다.
