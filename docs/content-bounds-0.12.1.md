# 실제 내용 영역과 가장자리 여백 — 0.12.1

2026-10-28 / versionCode 24.

0.12.0의 ‘오른쪽 끝’은 큰 박스만 오른쪽으로 옮겼다. 특히 공통 배치에서 시계가 가운데 정렬이면 글자 오른쪽에 큰 빈 공간이 남았다. 이번 수정은 시계·날짜·배터리의 실제 글자 윤곽을 측정해 선택·이동·크기 조절 영역과 렌더링을 일치시킨다.

## 사용 방법

1. 일반 편집 또는 **공통 배치 편집 → 전체 화면 편집**을 연다.
2. **요소 목록 → 시계 → 조정 → 오른쪽 끝**을 누른다. 현재 표시 크기를 유지하면서 내용에 맞는 영역으로 전환한다.
3. **좌우 여백 (%)**에 원하는 값, 예를 들어 `1.25`를 입력하고 **여백 적용**을 누른다. 입력 키보드의 완료로도 적용한다.
4. **내용 크기** 또는 모서리 손잡이로 크기를 조절한다. 오른쪽 기준에서 왼쪽 손잡이를 사용하면 오른쪽 간격을 유지한다.
5. **저장** 또는 **공통 저장**한다. 선택 프리셋 반영 여부는 기존 저장 흐름을 따른다.

여백은 가로·세로 각각 화면 길이에 대한 비율이며 0~40% 범위에서 입력한다. 가로 1.25%는 너비 2376px 화면에서 약 30px다. `0`은 글자 윤곽을 가장자리에 밀착한다. 위·아래 정렬은 위아래 여백을 사용한다. 글자 윤곽을 위한 미세한 안티앨리어싱 여유와 픽셀 반올림은 남는다.

시각이나 배터리 값이 바뀌어 내용 폭이 달라져도 선택한 가장자리 간격을 유지한다. 드래그·위치 슬라이더로 직접 옮기면 해당 기준을 해제한다. 화면보다 큰 내용은 화면 안에 들어오도록 축소한다. 위치 고정을 켠 요소는 내용 맞춤·크기·여백 변경도 잠긴다.

## 공통 배치와 기존 디자인

- 내용 맞춤 크기·가장자리 기준·여백을 위치·크기와 함께 공통 저장한다. 각 프리셋의 글꼴이 달라도 여백을 실제 영역 기준으로 계산한다.
- 폰트·색상·이전 글자 스타일 값·원래 배치는 보관한다. 공통 연결을 끄면 원래 배치를 복원한다.
- 이미 저장된 디자인을 자동 변환하지 않는다. 내용 맞춤 또는 가장자리 버튼을 선택할 때 새 방식을 사용한다.
- 기존 전체 화면 편집, 겹친 요소 선택, 사진·GIF, 게이지, 프리셋 순환과 저장 흐름을 유지한다.
- 작은 영역에서 글자를 가리지 않도록 모서리 표시를 줄였으며 터치 조작 범위는 유지한다.

## 검증

단위 검사 **97개**, Fold6 별도 검사 앱의 최종 회귀 **33개**가 모두 통과했다. Debug·Validation·계측 APK 빌드가 통과했고, Lint는 각 오류 0개·기존 경고 14개다.

실사용 설정·근무 기록·미디어 7개 파일은 검사 전후 해시가 동일했다. 검사 패키지 2개를 제거했고 자동 감시의 foreground 실행·알림 서비스 연결을 확인했다. 이후 사용자 승인에 따라 **0.12.1 / versionCode 24를 Fold6에 업데이트 설치**했다. 설치 직후와 자동 감시 복원 후에도 7개 파일 해시가 모두 일치했다. 기기 패키지 정보와 앱 화면에서 버전을 확인했고, 기존에 켜져 있던 자동 감시를 다시 켰다. 실사용 프리셋의 배치·여백은 변경하지 않았다.

핵심 검사는 기본·이사만루·메이플스토리·꾹꾹체 네 글꼴에서 큰 가운데 시계의 변환 전후 실제 픽셀 크기, 영역과 글자 윤곽의 밀착, 오른쪽 1.25% 여백을 비교한다. 13:09·11:11·23:58로 바꾼 뒤에도 간격과 지정 크기를 확인한다. 날짜·배터리 전체 줄의 영역, 0% 밀착, 위쪽 2% 여백, 공통·일반 저장과 재진입, 이전 데이터 호환성도 검사한다.

초기 검사에서 기기의 비선형 글자 배율로 인한 크기 차이와 글꼴 메트릭의 빈 영역을 발견했다. 기존 표시 크기를 배율까지 보정해 보관하고 글자 윤곽으로 측정하도록 수정했다. 새 여백 적용 버튼과 색상 적용 버튼을 혼동한 기존 검사는 버튼 문구를 구분한 뒤 다시 실행했다.

잠금·충전·자세별 자동 진입·종료와 내부 화면·접힘 전환, 장시간 사용은 이번 변경에서 다시 검사하지 않았다. 실기기 검사는 실사용과 분리된 패키지를 사용한다.
