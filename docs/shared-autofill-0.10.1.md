# 공통 배치의 없는 요소 자동 추가 — 0.10.1

2026-10-27 / versionCode 20.

공통 배치를 사용하는 프리셋과 현재 화면에 선택된 요소가 없으면 자동으로 추가한다. 기존 요소의 위치·크기·고정 여부는 공통 배치를 따르며, 기존 색상·미디어·방향 등의 개별 설정은 유지한다.

## 동작

- 공통 배치 선택 시 기준 요소의 설정을 함께 보관한다. 없는 요소를 추가할 때 GIF 파일·맞춤·속도·반복·불투명도, 게이지 방향·색상 등을 복사한다.
- 기존 요소는 복제하지 않고, 없는 슬롯만 추가한다. 같은 종류의 두 번째 요소만 공유한 경우 첫 번째를 불필요하게 만들지 않는다. 자동 추가된 요소의 대응 번호와 ID는 저장·재진입에도 유지한다.
- 공통 배치를 사용하지 않는 프리셋에는 추가하지 않는다. 기존 프리셋의 요소·순서·개별 설정을 유지하고 새 요소를 뒤에 추가한다.
- 자동 추가된 요소의 색상·재생 설정은 해당 프리셋에서 편집할 수 있다. 공통 연결 중 위치·크기·고정은 공통 편집기로 관리한다.
- 공통 선택에서 제외하거나 연결을 꺼도 추가된 요소는 프리셋에 남는다. 연결을 끈 뒤 일반 편집에서 제거할 수 있다. 기존 요소는 원래 배치로, 추가된 요소는 처음 복사한 배치로 돌아간다.
- 기존 위치만 저장한 공통 배치는 현재 저장/편집 화면과 프리셋에서 기준 요소를 찾아 보충한다. 기준 요소를 찾지 못하면 해당 종류의 기본 설정을 사용한다. GIF 원본 파일 자체가 없으면 재선택이 필요하다.
- 기준 GIF를 공통 배치가 참조하는 동안 원본 프리셋을 삭제해도 파일을 유지한다. 어떤 화면·임시 저장·프리셋·공통 기준에서도 사용하지 않을 때만 정리한다.
- 직접 추가 요소 20개를 유지하면서 공통 추가 요소를 포함해 최대 40개를 보관한다. 한도 초과 시 변경 전체를 저장하지 않고 안내한다. 기존 요소를 잘라 내거나 일부 프리셋만 변경하지 않는다.

편집기의 탭마다 스크롤 위치를 분리했다. 프리셋 목록 아래에서 요소 탭으로 이동해도 요소 선택 목록이 처음부터 보인다. 공통 배치로 추가된 GIF는 편집 선택을 자동으로 가져가지 않는다.

## 검증과 설치

- Debug·Validation·계측 APK 빌드, 단위 검사 **90개 통과**. Debug·Validation Lint 각각 오류 0개·기존 경고 14개.
- Galaxy Z Fold6(Android 16)의 별도 검사 앱에서 관련 고유 **23개 검사 최종 통과**. 최초 22개 통과·1개 실패 후 화면 수정과 최종 화면 검사 9개를 통과했다.
- 최초 실패는 요소 선택이었다. 자동 추가 GIF의 선택 이동을 없애고 저장 완료를 기다려도 실패가 남았다. 실제 캡처에서 이전 탭의 스크롤 때문에 선택 목록이 미리보기 뒤로 가려진 것을 확인해 탭별 스크롤을 분리했다. 진단·실패 로그도 보관한다.
- 시계만 있던 화면에 게이지·GIF 자동 추가, 개별 색상 편집·프리셋 반영·재진입, 연결 해제 후 추가 요소 보존과 제거를 확인했다.
- 이전 공통 배치 복원, 두 번째 요소만 추가, 기존 요소 20개를 보존한 22개 저장·디스크 재개방, 원본 프리셋 삭제 후 GIF 유지, 한도 초과 시 전체 저장 실패를 확인했다.
- 기존 공통 선택·드래그·배치 조정·프리셋 저장 팝업·연속 편집·근무 상태·설정 호환성과 GIF 실제 프레임 검사도 통과했다.
- 실제 캡처를 확인했다. 사용 앱에 새 버전을 설치한 뒤의 잠금·충전·자세에 따른 자동 진입·종료와 장시간 동작은 재검사하지 않았다.

세부 결과는 검증 집계 (`output/shared-autofill-0.10.1/verification.json`, 로컬 전용)와 데이터·서비스 보존 기록 (`output/shared-autofill-0.10.1/preservation.json`, 로컬 전용)에 기록했다. 기존 설정·근무 기록·미디어 7개 파일의 검사 전후 해시가 같고 자동 감시·알림 연결을 유지했다. 개인 파일 내용을 내보내지 않았으며 검사 앱 2개를 제거했다.

사용자 승인 후 사용 앱을 **0.10.1 / versionCode 20**으로 업데이트했다. 설치 직후 기기 연결이 끊겼으나 재연결 후 앱의 **자동 스탠바이 켜기**로 감시를 복구했다. 자동 감시의 foreground 실행과 알림 서비스 연결을 확인했고, 설치 전·설치 직후·감시 복구 후 설정·근무 기록·미디어 7개 파일의 해시가 모두 일치한다. 검사 앱은 남아 있지 않다.
